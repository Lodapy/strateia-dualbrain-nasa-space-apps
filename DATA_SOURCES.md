# Data sources and licences

All data was accessed in November 2026. Most satellite processing used Google Earth Engine.

## NASA data

| Dataset | Use in this project | Terms |
|---|---|---|
| NASA FIRMS VIIRS 375 m (archive and NRT) | Fire hotspots 2012–2026, persistent burn sites | NASA open data; cite FIRMS |
| NASA Black Marble VNP46A2 | Night lights, lit-area trend | NASA open data |
| NASA POWER | Daily rain and wind (0.5° cell) | NASA open data |
| NASA NASADEM 30 m | Terrain, flood stages, runoff lines | NASA open data |
| NASA MODIS MAIAC MCD19A2 | Aerosol optical depth, dry-season turbidity | NASA open data |
| Landsat Collection 2 Surface Temperature (USGS/NASA) | Summer land-surface temperature, heat island | Public domain |

| Dataset | Use | Terms |
|---|---|---|

| Copernicus Sentinel-2 L2A (ESA) | Yearly water 2022–2026 | Same as above |
| Copernicus Sentinel-5P TROPOMI (ESA) | NO₂, aerosol index | Same as above |
| Copernicus DEM GLO-30 (ESA) | Terrain check | Copernicus DEM licence |
| ESA WorldCover 2021 | Built-up and tree cover | CC BY 4.0 |
| JRC Global Surface Water (EC JRC, from Landsat) | Yearly water 1990–2021 | Free, with attribution |
| GHSL GHS-POP (EC JRC) | Modelled population | CC BY 4.0 |
| Google Open Buildings 2.5D Temporal | Building heights, year first seen 2016–2023 | CC BY 4.0 |
| OpenStreetMap | Building footprints, neighbourhoods | ODbL 1.0 (© OpenStreetMap contributors) |
| NOAA CPC ONI | El Niño index | Public domain |
| Press reports citing SEN, Itaipú and the municipality (QZ, Hoy, EFE) | October 2026 flood events and affected families | Facts cited with source in each row |
